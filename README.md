**# AutoLoc**



**## Présentation du projet**

**AutoLoc est une application de gestion de location de voitures permettant aux clients de consulter les véhicules disponibles et de gérer leurs réservations.**



**## Acteurs et cas d'utilisation**



**### 1. Client**

**- Créer un compte et se connecter.**

**- Consulter les véhicules disponibles.**

**- Rechercher un véhicule selon ses critères.**

**- Réserver un véhicule.**

**- Consulter et annuler ses réservations.**

**- Consulter son historique de location.**



**### 2. Agent d'agence**

**- Consulter les réservations des clients.**

**- Enregistrer les départs et les retours des véhicules.**

**- Gérer les contrats de location.**

**- Vérifier la disponibilité des véhicules.**

**- Mettre à jour l'état des véhicules.**



**### 3. Responsable d'agence**

**- Gérer le parc automobile de l'agence.**

**- Superviser les agents et les réservations.**

**- Consulter les statistiques et les revenus.**

**- Valider et suivre les opérations de location.**



**### 4. Administrateur**

**- Gérer les comptes utilisateurs et les rôles.**

**- Gérer les agences.**

**- Configurer les paramètres de l'application.**

**- Superviser l'ensemble du système.**



**## Technologies prévues**

**- Langage : Java**

**- Gestion de projet : Maven**

**- Versionnement : Git et GitHub**



**## Objectif**

**Faciliter la gestion des locations de voitures et améliorer le suivi des réservations et des véhicules.**
